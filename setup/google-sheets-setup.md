# Google Sheets (& Google API) Setup

This guide sets up Alice's local Google API token, which enables Python-based access to **Gmail**, **Google Calendar**, and **Google Sheets** — all using a single shared OAuth token.

---

## File Layout

```
credentials/
├── google_credentials.json   ← Download from Google Cloud Console (secret, gitignored)
└── google_token.json         ← Generated by setup script (secret, gitignored)
```

---

## Prerequisites — Google Cloud Console

1. Go to [Google Cloud Console](https://console.cloud.google.com/) → select or create a project.
2. **Enable APIs** — navigate to *APIs & Services → Library* and enable:
   - Gmail API
   - Google Calendar API
   - Google Sheets API
   - Google Drive API
3. **Create OAuth credentials** — go to *APIs & Services → Credentials → Create Credentials → OAuth 2.0 Client ID*:
   - Application type: **Desktop app**
   - Name: anything (e.g. `Alice`)
4. **Download the JSON** — click the download icon next to the new client, save as:
   ```
   credentials/google_credentials.json
   ```

---

## OAuth Scopes

Alice uses a combined token covering all Google services:

| Scope | Used by |
|---|---|
| `gmail.modify` | Gmail read/send/label scripts |
| `calendar` | Google Calendar scripts |
| `spreadsheets` | Google Sheets CRUD |
| `drive.readonly` | List spreadsheets via Drive API |

All scopes are requested in a single auth flow — one token covers everything.

## Setup Steps

### 1. Install dependencies

```bash
{ALICE_ROOT}/.venv/bin/pip install \
  google-auth \
  google-auth-oauthlib \
  google-auth-httplib2 \
  google-api-python-client
```

### 2. Run the auth script

```bash
{ALICE_ROOT}/.venv/bin/python {ALICE_ROOT}/setup/google_auth_setup.py
```

This will:
- Check that `credentials/google_credentials.json` exists
- Open a browser window for Google OAuth consent
- Ask you to log in and grant the listed permissions
- Save the token to `credentials/google_token.json`

### 3. Verify

```bash
ls {ALICE_ROOT}/credentials/google_token.json
```

If the file exists, setup is complete. Run Alice's connection check to confirm:

> "check google sheet connection" or "check connections"

## Token Refresh

- **Auto-refresh:** The token refreshes silently when it expires (as long as the refresh token is valid).
- **Manual re-run:** If the token is revoked (e.g. you removed app access in Google account settings), re-run the auth script:
  ```bash
  {ALICE_ROOT}/.venv/bin/python {ALICE_ROOT}/setup/google_auth_setup.py
  ```

## Troubleshooting

| Error | Cause | Fix |
|---|---|---|
| `FileNotFoundError: credentials/google_credentials.json` | Credentials file not downloaded | Download from Google Cloud Console (see Prerequisites) |
| `Token has been expired or revoked` | Access was revoked in Google account | Re-run `google_auth_setup.py` |
| `Access blocked: This app's request is invalid` | Scopes not enabled or OAuth consent screen not configured | Enable APIs in Cloud Console; configure consent screen |
| `HttpError 403: The caller does not have permission` | API not enabled in Cloud project | Enable the specific API (Sheets/Drive/Gmail/Calendar) in Cloud Console |
| `HttpError 401: Invalid Credentials` | Token file corrupted | Delete `credentials/google_token.json` and re-run auth script |
| `ModuleNotFoundError: google` | Dependencies not installed | Run pip install step above using the venv Python |
